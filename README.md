# На память

Сервис необычных поздравлений: анимированное видео-поздравление с говорящим "клоном" клиента и именные песни с клипом.

## Услуги

1. **Анимированное поздравление** — фото + текст → говорящий аватар зачитывает поздравление. Опционально: помощь с написанием стиха.
2. **Именная песня + клип** — текст песни + музыка (Mureka) → готовая песня → клип на её основе.

## Каналы

Telegram-бот и сайт работают поверх одного общего бэкенда (приём заказа, генерация, оплата) — не дублируем логику.

## Стек (план)

- Бэкенд: Node.js
- Видео-аватар: HeyGen или D-ID (нужен API-ключ)
- Музыка: Mureka API (нужен API-ключ, royalty-free, легальный публичный API)
- Бот: Telegram Bot API
- Сайт: Vercel
- Хостинг бэкенда/бота: Railway
- Оплата: ЮKassa или Тинькофф Касса (позже, к запуску)
